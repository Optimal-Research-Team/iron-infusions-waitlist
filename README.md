# IV Iron Infusions — Landing page (review build)

Landing page for Optimal Clinic's IV iron infusion program in Barrie, opening November 2026.

**Live preview:** https://optimal-research-team.github.io/iron-infusions-waitlist/
**MD referral form:** https://optimal-research-team.github.io/iron-infusions-waitlist/referral-form.html

## Status

This is a **review build for clinical sign-off**, not the production page:

- `noindex` is set, so search engines won't list it.
- The email and waitlist forms are not connected to anything yet; nothing typed into them is saved or sent.
- The waitlist count and launch date are placeholders.

## Files

| Path | What it is |
|---|---|
| `index.html` | The landing page |
| `referral-form.html` | One-page MD/NP referral form (print or save as PDF, then fax) |
| `support.js` | Rendering runtime the pages need |
| `img/` | Photos, engravings and the social preview image |
| `referral-form.pdf` | Print-ready Letter PDF of the referral form |
| `source/` | Claude Design source files |
| `HANDOFF.md` | Engineering handoff: structure, behaviour, wiring, SEO, tokens, open items |

The source of truth is the Claude Design project. This repo holds an exported copy.
